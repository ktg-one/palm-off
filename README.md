# palm-off

Palm an idea off the chat. Plan it, push a private repo, leave one daily growth cron and one weekly review reminder.

## Outcome

A user idea becomes a repo plus two schedules, not a thread.

## Run

1. Hand over one idea.
2. Operator writes `PLAN.md`, pushes `ktg-one/<slug>`, creates `<slug>-daily-growth` and `<slug>-weekly-review`.
3. Next action is the Day-1 line in `PLAN.md`.

Skill contract: `SKILL.md`.
